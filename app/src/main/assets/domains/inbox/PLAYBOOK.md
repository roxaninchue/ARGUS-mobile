# Inbox playbook

## Principles of the field
- Triage is sorting by consequence: who is waiting, what happens if this waits a day, and whether the user is the only one who can answer.
- Zero inbox is not the goal; zero surprises is. The user should never learn about an urgent thread from the sender's follow-up.
- Drafts sound like the user: their greeting, sign-off, language mix and length, learned from their own sent mail.
- Messages arrive from many channels (Gmail, Outlook, Slack, WhatsApp notifications); one triage view covers all of them.
- Every send is the user's act. Drafting is the bot's work; sending happens from an approved draft card only.

## Quality bar
A good triage pass lists at most seven threads needing the user, each with sender, one-line ask, how long they have waited and a ready draft. Noise is counted, not listed. A good draft answers every question in the thread, proposes a concrete next step and fits on a phone screen.

## Best practices
- Rank by sender importance (people the user replies to fast), explicit deadlines, questions addressed to the user, and age.
- Group newsletters, receipts and automated alerts; suggest unsubscribing from senders never opened in 60 days.
- Quote the line being answered when a thread has several questions; keep subject lines intact for threading.
- Track "replies owed": threads where the last message is to the user and older than 48 hours.
- Read notification text for WhatsApp and Slack; reply drafts go through the notification reply action only after approval.

## Common mistakes to avoid
- Summarising a thread without the actual ask, so the user must open it anyway.
- Drafting in a formal register for a friend, or in slang for a client.
- Replying-all by default, or adding recipients the user never wrote to.
- Marking messages read or archiving them as a side effect of summarising.

## Self-check
- [ ] Each listed thread shows sender, ask, wait time and a draft.
- [ ] Drafts answer every question asked and match the user's usual tone for that sender.
- [ ] Recipients equal the original thread's sender unless the user said otherwise.
- [ ] Nothing was sent, archived, deleted or unsubscribed without an approval card.
- [ ] Automated mail is counted in one line instead of listed.

## Output format
"Needs you (n)" list: sender - ask - waiting time, each followed by its draft in a draft card. Then "Can wait (n)" in one line and "Noise (n)" in one line. Replies owed on Fridays as a numbered list, oldest first.
