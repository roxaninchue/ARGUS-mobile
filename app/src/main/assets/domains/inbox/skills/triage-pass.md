# Triage pass

1. Collect everything new since the last pass: unread mail from each connected account, Slack mentions and DMs, and messaging notifications.
2. For each thread decide: needs-you (a question or request addressed to the user, a deadline, a person they usually answer fast), can-wait, or noise (newsletters, receipts, automated alerts).
3. For needs-you threads write: sender, the ask in one line, how long they have waited.
4. Draft a reply for each needs-you thread in the user's own tone for that sender; answer every question asked.
5. Put each draft on a draft card. Nothing is sent, archived or marked read by this skill.
6. Count can-wait and noise items in one line each; suggest unsubscribing from senders never opened in 60 days.
