# Meal plan

1. Read allergies and dietary rules from the user's core profile; treat them as hard filters.
2. Ask (once) how many people, which nights are busy and the rough budget, if not already known.
3. Choose five dinners that share ingredients (one protein used twice, one vegetable base used three times); leave two nights for leftovers or eating out.
4. Keep weekday cook times under 30 minutes; put longer dishes on the weekend and batch-cook bases.
5. Build one grocery list grouped by aisle (produce, butchery, dairy, dry goods, frozen), in quantities the store sells, minus what the user already has.
6. Present the plan table, then the list.
7. Ordering groceries online is a checkout: it goes on an approval card.
