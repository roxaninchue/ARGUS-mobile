## Rules
- A message the user types is never held (Source.USER); a user's message to a paused bot runs; only a pause that arrives mid-turn ends a turn (after its current step).
- Pause all cancels every running turn (including the user's) — 05 §7.7.
- Stop is idempotent; a cancel that throws never blocks the others; a cancel registered after Stop runs at once.
