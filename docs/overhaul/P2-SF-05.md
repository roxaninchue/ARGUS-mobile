## Rules implemented
- **Chain.** `hash = SHA-256(canonical(row))`, canonical = length-prefixed every column but `hash` (`v1` tag first; null ≠ ""). Row 1's `prev_hash` = 64 zeros. `verify` reports the first bad row: `BAD_HASH` (edited), `BROKEN_LINK` (deleted / reordered / inserted), `BAD_GENESIS` (front removed), `BAD_SEQUENCE` (ids skip). With the head kept outside team.db: `TRUNCATED` (tail cut, or table emptied) and `HEAD_MISMATCH` (tail rewritten and re-sealed). A head that lags by a row (app died between commit and head write) is accepted if the row it names is unchanged.
- **What is logged.** `Audit.shouldRecord`: everything except a READ that ran on its own (05 §7.6).
- **Redaction** (on append, args and result): secret-named keys in JSON, JSON-in-a-string, `key=value`, `key: value` → `[redacted]`; `Bearer/Basic …` → `[redacted]`; then `PasteGuard.detect` (token formats, Luhn cards, "my password is …", high-entropy) → `[redacted <label>]`. Secure Form handles `{{secret:x}}` are kept. Redaction runs on the first 4000 chars before the 500-char cut, so a cut can't leave half a secret.
- **`chain` column**: parent bot ids joined by `>` (outermost first).
- **SpendGuard.check** order: amount ≤ 0 → DENY · other currency → ASK · over per-tx max → DENY · merchant not in a non-empty allow list → ASK · cap 0 → ASK · spent + amount > cap → ASK · else ALLOW. ALLOW only lifts the money check; `Policy.decide` (P2-SF-01) still applies every other rule (e.g. proactive SPEND never unconfirmed). No dependency on Policy.kt.
- **Month** = calendar month in `SpendSettings.zone` (IANA, default the phone's zone), `[1st 00:00, next 1st 00:00)`.
